## What this package does

This reproducible analysis defines a naive mean-prediction baseline, freezes one 80/20 split, compares linear regression, Ridge and Lasso candidates, selects regularization strengths using 5-fold cross-validation on training data only, and inspects residuals, influence, heteroscedasticity, a learning curve, BMI-based critical slices, and large test errors.

## Dataset choice and limitation

The project uses `sklearn.datasets.load_diabetes`, a small, bundled regression benchmark (442 rows, 10 input features). It is included with scikit-learn, so the analysis does not need to fetch a dataset from the internet. Its target is a quantitative disease-progression benchmark measure; this is **not** a clinical tool and must not be used for patient-level diagnosis or treatment. If the instructor assigned a different dataset or expects a specific dataset from A1/A2, replace this dataset only after confirming the assignment requirement and update the provenance and data card.

Because the target is continuous and this is a regression assignment, logistic regression is not used: logistic regression is a classification model. Linear, Ridge and Lasso regression are the appropriate candidates for this target.

## Run it

Python 3.12 is recommended. In a clean environment:

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
python src/run_analysis.py
```

Open `notebooks/DS_A3_regression_baseline_diagnostics.ipynb` and run all cells top-to-bottom. The notebook calls the same script to avoid duplicated analysis logic. Results and figures are written to `results/` and `figures/`.

## Key files

- `src/run_analysis.py` — full reproducible analysis

- `results/diagnostics_summary.json` — Breusch–Pagan and influence flags
- `results/critical_slice_metrics.csv` — performance across BMI quartiles
- `results/largest_test_errors.csv` — difficult cases for error analysis
- `figures/` — diagnostic plots
- `docs/` — claim boundary, data card, reproduction guide and AI-use log template
